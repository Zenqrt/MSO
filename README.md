# Mini Squid Olympics
A tournament network that includes Match Frenzy, Parkour Race, TNT Run, One in the Chamber, and Spleef. This was a tournament in Summer 2024 made for the Mini Squid guild. 
This uses Velocity as a proxy framework, RabbitMQ for messaging between servers, and Minestom for minigame implementations.
